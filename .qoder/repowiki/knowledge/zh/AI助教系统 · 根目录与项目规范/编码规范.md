- 开发/生产通过 `DEV_MODE` 环境变量切换基础设施（SQLite→MySQL、本地存储→MinIO、同步任务→Celery、空检索→Qdrant），所有服务层需对可选依赖做降级处理。
- Agent 交互统一采用 SSE 流式返回，事件类型固定为 `reasoning` / `tool_call` / `tool_result` / `token` / `error` / `done`，前端通过专用 hook 消费。
- 所有批改/测评类工具必须接收 `strict_level`(1-5) 参数，全局严格等级由用户预设模板注入系统提示词，确保评分尺度一致。
- 作业状态机遵循 `pending → splitting → splitted → grading → completed`（兼容旧 `processing`），分析完成后自动更新知识状态。
