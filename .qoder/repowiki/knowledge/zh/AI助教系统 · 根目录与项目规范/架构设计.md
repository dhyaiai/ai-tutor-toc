本模块为纯配置/文档型根目录，不承载运行时代码，主要职责是统一项目的启动方式与环境约定：
- `start_dev.bat` 是 Windows 一键开发入口，按顺序安装后端 `requirements.txt` 和前端依赖，并以独立子进程分别拉起 `uvicorn app.main:app --reload`（8000）与 `npm run dev`（5173），Vite 通过代理将 `/api` 转发到后端。
- `.env.example` 定义双模式开关 `DEV_MODE`：true 时走 SQLite + 本地 `./uploads/` 存储；false 时切换 MySQL + MinIO + Redis + Qdrant 的生产栈，由 `backend/.env` 实际生效。
- `CLAUDE.md` 作为 Claude Code 的上下文约束，固化了 Python 3.10、FastAPI+SQLAlchemy 2.0 异步 ORM、Alembic 迁移、Celery/dev_runner 双任务执行器、ReAct Agent SSE 对话等架构决策。
- `AI助教agent.md` 与 `ai助教.md` 是面向 Vibe Coding 的完整规格文档，覆盖 Agent 工具契约（Function Calling）、口语测评/作文批改两大独立板块、实时语音链路、预设模板体系与严格评分等级，作为前后端实现的权威需求来源。
- `.gitignore` 排除 Python 缓存、`.db` 开发库、`uploads/`、`.env`、`node_modules/` 等生成物，保证仓库仅保留源码与配置。
