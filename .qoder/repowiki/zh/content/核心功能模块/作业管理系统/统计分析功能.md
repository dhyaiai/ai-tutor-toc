## 简介
本文件面向“统计分析”能力，覆盖作业相关的统计指标（班级平均分、最高分、最低分、分数分布）、成绩趋势分析（个人学习轨迹、班级进步情况、知识点掌握度）、报告生成机制（PDF、Excel、可视化图表）、实时统计更新（增量计算、缓存策略、性能优化）、异常检测（成绩波动预警、作弊行为识别）以及对外API接口与扩展方法。文档同时提供前后端交互流程、数据模型与关键算法的图示化说明，帮助开发者快速理解并扩展系统。

## 项目结构

- 服务层：聚合统计、知识追踪、PDF渲染等

### 基础统计指标（班级平均分、最高分、最低分、分数分布）
- 数据来源：作业与用户成绩记录
- 计算逻辑：按班级维度聚合分数，计算均值、极值与分布区间计数
- 输出格式：结构化JSON，包含各指标与时间范围

```mermaid
flowchart TD

GroupByClass --> ComputeMax["计算最高分"]
GroupByClass --> ComputeMin["计算最低分"]
GroupByClass --> ComputeDist["计算分数分布区间"]
ComputeAvg --> Merge["合并指标"]
ComputeMax --> Merge
ComputeMin --> Merge
ComputeDist --> Merge
Merge --> Return(["返回统计结果"])
```

### 实时统计更新机制（增量计算、缓存策略、性能优化）
- 增量计算：仅处理新增或变更的作业与成绩记录，降低全量重算成本
- 缓存策略：对热点统计结果进行短期缓存，减少重复计算
- 性能优化：分页读取、并行聚合、索引优化

```mermaid
flowchart TD
Trigger(["触发更新"]) --> CheckCache["检查缓存是否命中"]
CheckCache --> |命中| ReturnCached["直接返回缓存结果"]
CheckCache --> |未命中| FetchDelta["拉取增量数据"]
FetchDelta --> IncrementalCalc["增量计算指标"]
IncrementalCalc --> UpdateCache["更新缓存"]
UpdateCache --> Persist["持久化结果"]
Persist --> ReturnNew["返回新结果"]
```

### 异常检测（成绩波动预警、作弊行为识别）
- 成绩波动预警：基于时间序列的方差与阈值判断，识别显著波动
- 作弊行为识别：结合答题时长、相似度、异常模式进行风险评分

```mermaid
flowchart TD
Start(["开始"]) --> Collect["收集成绩与行为数据"]
Collect --> Volatility["计算波动指数"]
Volatility --> Threshold{"超过阈值?"}
Threshold --> |是| Alert["发出预警"]
Threshold --> |否| Normal["正常状态"]
Collect --> Similarity["计算答案相似度"]
Similarity --> RiskScore["生成风险评分"]
RiskScore --> HighRisk{"高风险?"}
HighRisk --> |是| Flag["标记可疑"]
HighRisk --> |否| Clean["无异常"]
Alert --> End(["结束"])
Normal --> End
Flag --> End
Clean --> End
```

## 性能考虑
- 增量计算优先：仅在数据变更时重新计算受影响指标
- 缓存热点结果：对高频查询设置合理过期时间
- 并行聚合：对多班级或多时间段的数据进行并行处理
- 索引优化：为作业ID、用户ID、时间戳建立合适索引
- 分页与限流：避免一次性加载大量数据导致内存压力

## 故障排查指南
- 统计结果为空：检查作业与成绩数据是否存在、时间范围是否正确
- 导出失败：确认PDF渲染器依赖是否安装、模板路径是否正确
- 异步任务堆积：检查Celery工作进程数量与队列配置
- 缓存不一致：清理缓存后重试，或调整缓存失效策略
