## 空壳结果重试修复（下午）

用户并发优化后跑真实作业，第 7/8/11/12 题报 `LLM 返回空壳结果`。排查确认：
- `ai_grader.py` 本次优化未改动（最后提交 8-14），空壳是 qwen 思考型模型的**既有**失败模式（推理预算耗尽后输出仅含元数据、语法完整的空 JSON）
- 真实缺陷：截断（finish_reason=length）会触发翻倍 max_tokens 重试，但空壳在 `_parse_single_result` 被静默转失败结果，**跳过了重试**——而翻倍预算恰是空壳的对症解法

**修复**（`backend/app/services/ai_grader.py` `_grade_chunk`）：
- 结果映射后检测空壳（`_is_empty_payload`）：非最后一次尝试 → raise 触发翻倍预算重试；最后一次 → 接受部分结果
- 新增 `best_partial`（空壳最少的部分成功结果）：最后一次尝试整体异常时兜底返回，避免丢掉已算好的题
- 已失败的题需重启后端后用"单题重分析"或重新分析恢复

## 关闭视觉模型思考模式（下午，P1 落地）

用户反馈"点击重新分析，四题有三题失败"，控制台显示 `评语不完整（疑似被截断）` → 重试后 `LLM 返回空壳结果` → question 标记 FAILED。确认根因：`VISION_MODEL=qwen3.7-plus`（阿里云 MaaS）属 qwen3.7 系列，**默认开启思考模式 enable_thinking=true**，推理 token 抢占 max_tokens 输出预算，导致长 JSON 评语被截断/空壳——早上的"翻倍预算重试"只能缓解、不能根治。

**修复**（就是早先标注的 P1 项，现在落地）：
- `backend/app/core/config.py`：新增 `VISION_ENABLE_THINKING: bool = False`（默认关闭思考）
- `backend/app/services/ai_grader.py`：`_grade_chunk` 的 `chat.completions.create` 增加 `extra_body={"enable_thinking": self.enable_thinking}`
- `backend/app/services/llm_json.py`：`request_llm_json` 新增 `extra_body` 参数（默认 None，向后兼容 DeepSeek 文本调用点）
- 同步覆盖其他 VISION_MODEL 调用点：`similar_generator.py`、`question_transcriber.py`、`composition_service.py`（作文批改首次+重试两处）、`oral_service.py`（听写）、`explain_service.py`（讲解多模态路径，`_try_llm` 加 `enable_thinking` 可选参）

**要点**：`enable_thinking` 非 OpenAI 标准参数，必须经 `extra_body` 透传；仅 VISION_MODEL（qwen3.7-plus）调用点传，DeepSeek 文本调用点不传。评分/转录等结构化 JSON 场景的解题推理已由 prompt 的 `solution_process` 字段承载，关思考不影响正确性、反而更稳。验证：py_compile 全通过。

## 多选题错选误给分修复

用户反馈"高二下学期期末模拟卷(四)第11题选到错误答案为什么还给分了"。查库确认：第11题(数学,多选题,满分6)学生=ACD 正确=AC 得分=3.0——学生多选了错误选项D，属"错选"，按规则应 0 分，模型却按"少选得一半"给了 3 分（评语里自己都写了"D判断错误"，自相矛盾）。

**根因**：多选题"错选=0/少选=一半/全对=满分"规则只在 prompt 里写死，无代码层兜底，模型偶发不遵守。

**修复**：
- `backend/app/services/ai_grader.py`：新增 `_normalize_choice_letters` + `_enforce_multi_choice_score`，在 `_grade_chunk` 返回结果前统一校正多选题分数（错选→0、少选→满分一半、全对→满分、未作答→0；含子题；纯字母答案才校验，混入 LaTeX/数字则跳过避免误伤）。批量分析与重分析都走 `_grade_chunk`，自动覆盖。
- 数据修复：第11题(762) score 3.0→0，重算作业59总分 60→57。
- 全库扫描（57 道多选题）另发现 4 道同类错选给分异常（未动数据，待用户确认）：
  - qid=295 数学第4次周末 第10题 ABC vs BCD 得分2.0/6
  - qid=296 数学第4次周末 第11题 ABD vs ACD 得分3.0/6
  - qid=482 数学第15次周末 第10题 ABD vs BD 得分3.0/6
  - qid=740 物理第4周周末 第6题 AC vs AD 得分3.0/6
